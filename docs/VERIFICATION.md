# 0.16.0 doğrulama kaydı

9 Kasım 2026 · GitHub aktarımı öncesinde temiz arşiv kopyasında yeniden çalıştırıldı.

| Kontrol | Sonuç |
| --- | --- |
| Bağımlılık kurulumu | Node.js 24 ile `npm ci` tamamlandı. |
| Node kontrol paketi | 30 betik geçti. Kapsam, hazırlık planı, vaka hesapları, modüller, kayıt kurtarma ve pilot yetkilerini içerir. |
| Yerel HTTP demo (`node check-demo.mjs`) | Üç örnek rolün oturumu, aday dosya teslimi, yönetici ataması, değerlendirici indirmesi, özel taslak ve adayın yayımlanan görüşe erişimi doğrulandı. |
| Dosya ve rol ayrımı | Başka hesaptaki özel prova notlarına erişim ve eski teslim ekranından savunma kaydetme reddedildi. |
| Office paketleri | 20 Word ve 20 Excel dosyası, 187 kaynak metni ve 92 tablo bağımsız kontrolü geçti. |
| Üretim derlemesi | `npm run build` tamamlandı. |

Bu kayıt yerel ve otomatik kontrolleri kapsar. Canlı iki hesaplı davet, masaüstü/mobil görsel kabul ve gerçek aday pilotu [kabul listesinde](../PREPILOT-ACCEPTANCE.md) açık olarak izlenir.
